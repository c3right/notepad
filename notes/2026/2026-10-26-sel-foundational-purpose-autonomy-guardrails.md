# SEL应用总规则：保护个性、自主性和儿童主体性，防止SEL变成服从教育

> **规则等级：本家庭SEL项目的长期应用准则。** 本篇在SEL专题中优先于“选哪个主题、什么顺序、怎样设计亲子卡”的具体实施建议；后续制作KASEL96册的单书卡、布鲁伊动画选集、弗洛格与阿尔菲等经典作品共读指南、简繁体SEL绘本选材，以及任何自动化/Agent的SEL素材整理时，**默认以本篇为共同审查约束**。本篇是基于研究证据与明确家庭教育价值选择形成的**项目内部规范**，不是CASEL官方认证制度、教育部规范、临床建议或学术界唯一共识。涉及人身安全、医疗或儿童保护，需按相应专业规则处理。
>
> **提出背景**：在规划三岁半儿童SEL路线时，成人不具备SEL专业训练，不希望参加一套理论学习计划；家庭拟使用KASEL《共情陪伴》新版13主题96册纸书（96段配套视频的“中文版”为用户从客服得到的答复，未直接试听）、布鲁伊国语动画及经典儿童文学。用户明确关注：SEL最终把孩子引向何方？会否以“懂事、会分享、会自控”为名压制个性？本篇用于回答目标，并将风险转为可执行原则。有关原先两版阅读方案，见文末关联。

## 一句话结论：SEL的目的是什么？

**SEL不是把孩子训练成安静、顺从、不哭、不生气、容易管理的“好孩子”。** 家庭希望孩子逐步成为：认识并表达自己的人；理解并尊重他人的人；在真实关系里能够协商、拒绝、合作、求助和修复的人；在安全及尊重他人权利的前提下，有自己的兴趣、个性、判断和选择能力的人。

一句话原则：**有自我，也有他人；有个性，也能合作；有情绪，也能逐渐调节；能遵守合理规则，也能表达不同意见；能体谅别人，也能保护自己。**

这不是把“个性”视作不能引导的固定天赋，也不是“孩子说什么都对”。要在**保护儿童的自主性**、**照顾他人权利与共同生活的需要**、**成年人对安全与适龄边界负责**之间取得平衡。

## 规则1｜把SEL的成功标准从“听话/好管理”改为“多一种真实能力”

### 三条并行发展主线，三岁半现在就都可以开始

| 主线 | 希望逐渐发展的东西 | 不应把它误写成 |
|---|---|---|
| **成为自己** | 能觉察感受与需要、表达喜好、保留兴趣、欣赏自身独特性、提出不同意见、保护身体和私人财物边界 | 积极、自信、不胆小、人人喜欢 |
| **与他人相处** | 理解不同视角；邀请和回应；允许拒绝；合作、协商、修复关系；尊重他人的身体/财产和选择 | 不吵架、总分享、处处让步、讨好所有人 |
| **有能力面对生活** | 面对挫折时会求助、暂停、换方法或继续；渐渐能自主调节，认识安全规则和选择后果 | 不哭、不生气、不怕、任何困难都坚持、无条件服从 |

三条不是学习阶段，不把“成为自己”排到合作和自控之后。**能说“不”、能有与他人不同的兴趣、允许喜欢独处，都是健康SEL的一部分。**

### 建议的观察方向（不能作为测验、排名或人格评判）

- 敢说“喜欢/不喜欢、我想要、我不舒服、停一下”；逐渐相信有人会认真倾听。
- 愿意寻找帮助，不必每一次都自己扛过去。
- 能接受他人与自己喜好不同；也逐渐学会尊重别人的拒绝。
- 与人发生冲突后，成人支持下有机会协商、退出、修复关系。
- 遇到难题，有权暂停、调整、求助与改天再试；参与自己感兴趣的游戏与探索。
- 成人并不追求孩子的哭闹次数、争辩次数、分享率下降或听话率提升；这些外显指标本身不足以判断SEL质量。

## 规则2｜八条“防跑偏”红线：以后所有SEL故事、视频和家长卡都要遵守

| 常见变形 | 应避免的教学目标/话术 | 替代原则 |
|---|---|---|
| **情绪管理 → 压抑情绪** | “哭不解决问题，不许生气/马上深呼吸” | 感受可以存在；保护安全、共同调节；平静后再探索方法 |
| **共情 → 牺牲自己** | “你要站在别人立场，所以先让给他” | 双方需要都重要；理解不等于必须答应 |
| **分享 → 剥夺边界** | “好孩子必须分享自己的心爱玩具” | 他人的物品先征求同意；个人可拒绝；公共资源可商量轮流 |
| **自控 → 绝对服从** | “大人说了就得做；安全课要听任何大人指令” | 清楚解释具体安全风险，成人负责保护；允许表达不适与拒绝不安全要求 |
| **抗挫 → 强迫坚持** | “不能放弃；哭说明意志力不够” | 再试、换方法、休息、求助都是有效选择；尊重当前负荷 |
| **责任 → 羞耻和机械道歉** | “做错就坏/马上说对不起才能结束” | 分清意外/故意、认识影响，选择合适的修复或补救 |
| **社交 → 外向化和讨好** | “你必须主动交很多朋友/不能拒绝别人” | 尊重慢热、独处和少量亲密友谊；教邀请、拒绝和寻求保护 |
| **SEL学习 → 训诫和考核** | “故事讲过了怎么还做不到？今天会背哪个策略？” | 初读好好享受故事；真实情境成人示范；不以背标准答案代替发展 |

**家长遇到与红线冲突的出版物成人提示**：无需自己复核96册所有文本，只需**跳过该句教育提示、照常读故事、采用卡片提供的安全替代表述**。不能把故事角色情节的“做得不好”误认成应该模仿；同样，也不必把每次犯错讲成说教课。

## 规则3｜“尊重自主”与“清晰边界”同时执行，不把自主误用成放任

| 事情类型 | 成人应承担的责任 | 儿童可以发挥的空间 | 例子 |
|---|---|---|---|
| **安全与基本权利的底线** | 立即阻止伤害、说明与保护相关的规则；不能让幼儿独担安全责任 | 感受被承认，能询问原因、表达不舒服 | 不打人；过马路成人牵护；对不愿意的身体接触可以明确拒绝 |
| **家庭共同生活的协调** | 定出合理范围，解释缘由和时间安排 | 在安全范围内选择顺序、方式，并有机会协商 | 要睡觉但可选先收积木还是先收绘本；公共玩具讨论轮流 |
| **儿童合理的个人偏好** | 尊重并提供条件；避免把成人审美当规则 | 尽可能自主作决定，也可表达不愿 | 选绘本、角色玩法、穿合宜衣服的颜色、是否出借自己的玩具 |

三岁半的自主性不是“所有决策由孩子拍板”，而是**即使某件事最终必须由大人决定，孩子的感受和声音也应当被看见**。投票或多数决定只能解决适合共同协商的小事，**不能靠投票取消个人身体权利或强迫交出私人财物**。

对“他人说不”也同样保护：不能用保护本家孩子的自主权来忽略同伴自主权。

## 规则4｜因材施教：不把“外向、情绪平稳、爱社交”当唯一好性格

- 慢热与谨慎：容许观察和逐步参与；可以喜欢一两个熟悉朋友或独处，不以“勇敢点、快去打招呼”持续施压。
- 高活动量、表达强烈：允许有活力、有主见；提供保护安全、切换环境与表达方式的支持，不把气质判断为坏人格。
- 敏感、易难过：情绪容易被触动不等于失败；提供安全感、情绪命名和适龄选择，避免嘲笑“太玻璃心”。
- 喜欢独立做事：支持胜任感，也明确告知求助合法；不追求所有事情都依赖家长或所有事情必须独立。
- 性格只是当前表现，不把任何儿童贴上“内向/不好合作/不听话”等固定标签，更不借SEL强行统一成一种“理想人格”。

判断某种教学是否合适，应看**这个孩子的年龄和理解能力、个人气质与兴趣、文化/语言/生活情境**，不要求一套同样行为标准跨儿童复制。

## 规则5｜幼儿阶段以“共同调节、榜样、游戏”为主，不依赖讲道理

**成人最简操作**（不是固定三步口令，也不要求孩子必须回答）：

1. **先护安全，承认事实与感受**：“你还想玩，现在停下来真的很失望。”
2. **仅在必要时清楚表达边界**：“你可以生气，我不会让你打人。”
3. **儿童恢复平静后提供一两个选择**：“现在想抱抱、休息，还是一起想别的办法？”

如果孩子激动得听不进去，先保护和陪伴，不做SEL问答。不把“深呼吸、数到四”等策略变成强制停止哭泣的命令。成人也可以示范：“我刚才急了，声音太大，我来道歉并改正；规则为什么存在我们还是可以讨论”。

**素材只做支持**：KASEL绘本讲明一种办法；同故事视频帮助看到角色的声音/动作；布鲁伊展示人物在游戏里的不同视角；弗洛格/阿尔菲等文学正常欣赏。**不要求看完一集立刻总结哲理或对照五能力打分**。

## 规则6｜所有后续SEL研究、选材和家长指导卡的“发布前审查协议”（供研究Agent使用，家长无需学习）

这是长期可复用的项目内部**工作准则**。准备给家长一张卡片或推荐一个故事前，研究/编辑者必须过以下核查：

1. **目标核查**：写清希望增加哪种儿童能力；若表达为“更听话、更少哭、更愿意让步、更会讨好成人”，改写目标。必要时标注同时保留什么权利。
2. **自主核查**：是否允许孩子有不同感受、个人偏好、明确拒绝和参与适龄选择？若没有，补充或调整材料。
3. **双向权利核查**：成人、儿童、同伴各自的合理需要是否都被照顾？“共情/分享”能否同时尊重所有权、个人空间、身体同意？
4. **安全边界核查**：是否清晰区分“可以有任何情绪”与“不能做伤害行为”？安全责任是否仍由成人承担？投票/合作会否侵犯个人权利？
5. **适龄及气质核查**：三岁半能否理解一个具体动作或感受？是否强加复杂心理推理、道德说教、必须外向/坚强的气质标准？
6. **证据等级核查**：分清出版社/官方故事已核实、旧版实审、新版未审、工作书名映射、创作性的SEL解读；**不把建议包装成证明有效的课程或原作台词**。
7. **低家长负担核查**：每张家长卡优先包含“什么情况下取用、成人一句话、一个可选动作、一个防偏提醒”；不要求家长先学理论、不要求每日打卡或考核儿童。
8. **外部资源核查**：视频实际能否播放、中文对白和策略歌曲是什么语言、剧情是否匹配纸书；没有亲测就保留待核，不伪称新版96册全部审阅。

### 不通过时如何处理（本项目的工作约定）

- **红线级**（强迫分享/同意、羞辱情绪、绝对服从、忽略欺凌或身体安全）：**暂停作为正面SEL指导素材推荐**；若文学作品作为故事阅读可仍保留，但须移除问题话术并说明上下文。
- **适龄级**（太复杂、抽象、多方心理推理）：保留为较晚年龄候选，或只取一个具体情境，不强迫三岁半儿童理解全部主题。
- **证据级**（新版书页/国语内容/标题对照尚未核）：标“候选/待验收”，可给出依题意的暂定用途，但不得编造分册实审结论、视频对白或效果数据。
- **风格级**（看完总提问、要求孩子复述标准答案）：缩成自然共读和一句成人示范，不影响作品本身被选择。

**这是对未来SEL内容生产的过程约束，并不改变既有原始研究发现。** 应在今后的每个家长方案中附本规则链接，对确实冲突的既有判断作有记录的修订。

## 规则7｜把既有KASEL优先主题解释成“优先处理的生活情境”，不是塑造人格的优先事项

之前的KASEL新版13主题优先候选是**生气4＋冲突解决10＋抗挫8＋共情6＝28册**。这反映三岁半更常见、材料较好操作的生活入口，**不是要求孩子特别多训练“不生气、无冲突、坚持、迁就”四种外在行为**。完整96册仍是资源库，不是96门必修课。

| 既有选材项 | 教学目标应怎样重新定位 | 尤其不能怎样用 |
|---|---|---|
| 《不能玩，很生气》（旧B-14已审） | 情绪被看见、能安全表达并在支持下尝试调节 | 强制孩子冷静、以不哭为成果 |
| 《一步一步慢慢来》（F-8已审） | 有权选继续、分步骤、求助或暂停 | “不能放弃、不许求助” |
| 《我们的感受不一样》（F-1已审） | 自己和别人的感受都真实 | 必须接受别人的解释 |
| 《被冷落，好难过》（D-14已审） | 失落可表达、成人提供支持和保护 | 把受排斥归因孩子“不会社交” |
| 《考虑他人的感受》（B-4已审） | 理解对方，但同时保护自己的合理需要 | 无条件让步 |
| 《停，听指令，才安全》（D-1已审） | 识别具体交通/活动危险与合理安全规则 | 必须听任何成年人一切命令 |
| 《犯错误了，怎么办》（A-4已审） | 分清错误、认识影响、学习补救 | 羞辱犯错和强迫机械道歉 |
| 《投票是个好办法》（E-8已审） | 表达偏好、商议合理小事、观察选择后果 | 用多数票剥夺少数人的个人权利 |

仅旧版13册实审；对应到新版书名仍是待实物确认的工作映射，不把上述表述当出版社引用。

### 对原96册SEL覆盖分析的约束

- 13出版主题**不等于**CASEL五项能力比例；“生气、适应、自控、抗挫”主题丰富，反映选题倾向，但不能仅凭书名定量证明哪项能力真正不足或干预低效。
- 必须**跨主题主动保留**自我认同、个人边界、观点差异、负责决策和修复关系；“责任感”不等于家务、“分享力”不等于让出自己的东西。
- 对新材料要先看儿童本身与生活情境，再按书籍出版社的主题定位查找，不能为凑五能力均衡而让三岁半大量接受不适龄说教。

## 七、研究证据与规范性取舍严格分开

| 来源/级别 | 主要实际支持什么 | **不**支持直接推断什么 |
|---|---|---|
| **CASEL官方2020框架与现行说明〔正式定义〕** | 健康身份认同、个人与集体目标、关系、共情、负责决策；五能力与支持自主行动有关 | 不能证明KASEL印刷版是CASEL认证教材，也不等于每项课程天然保护个性 |
| **CASEL Transformative SEL〔框架/研究实践方向〕** | 特别重视Identity（身份认同）、Agency（能动性）、Belonging（归属感）、合作解决问题和公平 | 不是所有旧版SEL教材都已贯彻，也不能称变革性SEL已验证每一具体家庭建议 |
| **Deci & Ryan自我决定理论〔理论＋跨领域经验研究〕** | 自主性、胜任感、关系感是基本心理需要；支持自主不是放任 | 不等于三岁半儿童能独立管理全部危险或家庭安排 |
| **Meuwissen & Carlson 2019〔随机指导的短期实验；128对三岁儿童/家长〕** | 父母更具自主性支持的拼图互动能改善当次自我调节表现 | 未长期追踪个性、自主精神或人格变化 |
| **Bradshaw et al. 2025〔238项研究、N=126,423的跨文化元分析〕** | 自主支持与较佳儿童心理健康呈正相关（r=0.30）；心理控制与较差状态呈正相关（r=0.26）；跨不同地区存在相似关系 | 关联不能单独证明因果，也不能断言所有儿童需相同选择空间 |
| **2026学前SEL元分析〔87项研究、20,293名3–5岁儿童〕** | 多种SEL干预平均可改善幼儿情绪与人际技能；未发现某一特定教学组件一直胜过其他组件 | 不证明KASEL96册或家庭自制卡片直接产生相同效果 |
| **NAEYC发展适宜性实践/ ZERO TO THREE气质建议〔专业指南〕** | 应尊重每个儿童的独特性、家庭文化与气质，使用游戏和优势导向的教学 | 不是“绝不推动儿童尝试新的社交能力” |
| **香港2021 Tuning in to Kids随机试验〔104名3–6岁儿童的家长〕** | 情绪教练干预在短期降低父母的惩罚性反应和养育压力，部分儿童情绪变化延后出现 | 不意味着普通家长必须参加TIK课程，也非证明所有家庭话术有效 |
| **Cipollone等2022对SEL隐性服从课程的批评〔理论/批判论文〕** | 指出SEL实践有被用于规范儿童行为、压制不同文化和表达方式的风险 | 不是对所有SEL教材普遍造成伤害的因果实验 |
| **《儿童权利公约》第12条〔国际公约规范〕** | 根据儿童年龄与成熟度重视其对自身事务的意见 | 不是让幼儿承担本应由成人处理的风险、或事事有最终决定权 |

## 可贴到任何未来研究任务书开头的短版规则

> **SEL应用总规则**：以儿童主体性、健康自我认同、自主性、胜任感和关系能力的发展为目标。**允许感受、约束伤害；理解他人、不牺牲自己；鼓励合作、不强迫分享；解释安全规则、不训练无条件服从；支持尝试，也允许求助/暂停；尊重气质与个人偏好，不以外向、安静、听话作为唯一标准。** 使用绘本和视频前须区分证据等级；普通家长只需一句话和可选实践，不承担课程设计或儿童SEL考核。遇到与本规则矛盾的教材提示时，跳过问题提示、保留故事阅读；必要时暂停正面教学推荐，并记录理由。
