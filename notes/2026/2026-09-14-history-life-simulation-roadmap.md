# 历史人生模拟阅读项目：路线图与进展

> 本笔记只维护**讨论脉络、项目路线、阶段状态和下一步**；具体字段规范另见：[Decision Atom 正式字段表 v1](./2026-09-14-history-decision-atom-schema-v1.md)。

## 一句话结论

项目已经从“找一批有代入感的历史书”推进为：**先建立一套尽量关闭上帝视角的历史人生模拟案例筛选系统，再去规模化筛人物、案例与书。**

当前已完成：目标定义 → D/L/W 三轨 → 原12类重构 → 两轮压力测试 → Decision Atom v1。

当前所在阶段：**进入第三轮实操编码测试之前。**

---

## 1. 项目目标

此前的世界史、中国史阅读框架偏宏观，主要解决：

> 世界/中国历史如何运行？制度、结构、长期因果怎样展开？

这套新路径解决另一个问题：

> **如果我是当事人，在那个时刻，只拥有他当时能够拥有的信息，我会怎么选？**

因此两条轨道的关系是：

- **宏观史：给地图。**
- **微观人生模拟：练驾驶。**

目标不是寻找古人的“标准答案”，而是扩充未亲身经历的人生样本，训练在信息不完备、关系变化、利益冲突、价值冲突、风险和时间压力下的判断。

---

## 2. 讨论脉络：路线是怎样一步步收敛的

### 阶段 A：从“人物传记”转向“人生情境”

最初直觉是：英雄、奸雄、中人物、小人物都可以提供人生样本；历史可以作为一种低成本人生模拟器。

随即发现：

- 人物与书籍数量无限；
- 一本传记里存在很多完全不同的选择；
- 以“人物”为筛选单位无法控制搜索空间。

于是第一次转向：**不先选人物，而先定义反复出现的人生情境。**

### 阶段 B：12类情境逐项打磨

最初提出12类：路径选择、弱势求存、高风险下注、坚持/止损、识人用人、合作与背叛、冲突与妥协、原则与现实、成功后的风险、危机、退场、时代中的普通人。

逐类打磨后发现：它们不是同一层级——有的是决策问题，有的是环境状态，有的是价值冲突，有的是人物尺度。

于是第二次转向：**不再保留“12个并列盒子”。**

### 阶段 C：形成 D / L / W 三种模拟模式

为了避免把所有微观史都硬切成“决策题”，确立三轨：

- **D — Decision**：如果我是他，此刻怎么办？
- **L — Life-course**：这个人几十年怎样变化？
- **W — World**：活在这种具体历史环境中是什么感觉？

当前设计最深入的是D轨；L/W后续再单独建设。

### 阶段 D：原12类重新分层

D轨目前形成7个核心决策原型：

1. D1 路径选择与身份绑定
2. D2 高风险承诺与机会窗口
3. D3 持续投入、转向与退出
4. D4 识人、授权与制衡
5. D5 合作、承诺与关系变质
6. D6 对抗、谈判与让步边界
7. D7 角色退出、身份脱钩与权力交接

原来的“弱势、成功、危机、结构巨变”改为**情境坐标**；“价值冲突”改为**规范性维度N**；人物层级、决策单位等另行记录。

### 阶段 E：第一次分类压力测试

第一批故意选择差异很大的样本：

- 古巴导弹危机
- 华盛顿1783年辞去军职
- 刘大鹏一生
- 柯达数字化转型

主要暴露：

- A：谁才是真正决策主体？
- B：知道结局之外，还有更强的“叙事污染”
- C：著名历史节点不等于真实决策点
- D：人物/事件/书不能直接等同于案例
- E：高层/中层/普通人的简单三分法过粗

其中C、D随后优先处理。

### 阶段 F：明确“真实决策窗口”和“Decision Atom”

形成两条关键原则：

1. **历史上更真实的是决策窗口，而不是戏剧性的“决定瞬间”。** Freeze应设在仍有现实选择、且尚未越过主要承诺阈值的位置。
2. **D类最小单位是 Decision Atom。** 不是人物、事件、一本书，而是：一个明确主体，在一个真实开放的决策窗口内，基于当时信息，在现实可行方案之间，对一个核心问题作出选择。

同时形成四层案例结构：

- Case Field：案例矿区
- Case Episode：案例段
- Decision Atom：决策原子
- Case Packet：最终阅读模拟包

### 阶段 G：进一步处理主体结构与叙事污染

A「决策主体结构」被细化为：

- Focal Actor
- Formal Authority
- Effective Decider(s)
- Decision Group
- Veto / Constraint Holders
- Implementers
- Action Locus（Direct / Recommend / Negotiate / Veto / Implement）

B「叙事污染」被拆为：

- 结果熟悉
- 因果预装
- 道德/人格标签
- 目的论污染
- 回忆性重构

并明确：**关闭上帝视角需要同时控制“主体边界”和“时间边界”。**

### 阶段 H：第二轮压力测试

第二轮覆盖第一轮没有充分覆盖的四类：

- 中层行动者：何如璋与琉球交涉
- 普通家庭：弗兰克一家进入藏匿状态
- 长期合作：卡内基—弗里克
- 真正价值困境：弗朗茨·雅格施泰特

主要新增认识：

- 决策主体要区分“能直接拍板”与“只能建议/谈判/执行”
- Deciders 与 Affected Parties 必须分开
- D5 / 部分D6允许 Paired Focal Perspective 双视角顺序模拟
- 真正的规范性困境必须通过 Normative Open-Conflict Test
- 备用方案“何时启动”可能形成独立问题，但暂不升级为新原型

### 阶段 I：Decision Atom v1

两轮压力测试之后，已整理出正式工作版：

- 硬字段 / 核心字段 / 专属模块 / 评分字段
- D1—D7 / N
- 决策窗口与Freeze
- 主体拓扑
- 信息集与选项证据
- 叙事污染
- 情境坐标
- D5 / N专属模块
- Case Field / Episode / Atom / Packet
- Sources 与案例分离

详见：[Decision Atom 正式字段表 v1](./2026-09-14-history-decision-atom-schema-v1.md)。

## 3. 当前项目架构

目前最稳定的整体结构是：

> **模拟模式 D / L / W**
> ↓
> **若为D：确定 Decision Atom**
> ↓
> **D1—D7 / N 主决策原型**
> ↓
> **主体拓扑 + 行动权位置**
> ↓
> **真实决策窗口 + Freeze + 承诺阈值**
> ↓
> **当时信息集 + 现实选项集**
> ↓
> **情境坐标：强弱 × 时间压力 × 环境变化**
> ↓
> **叙事污染与史料后见性审计**
> ↓
> **准入 / 评分**
> ↓
> **再从案例反推书与史料**
> ↓
> **最终制作 Case Packet**

这里最重要的原则仍然是：

> **先筛案例，再筛书；书是案例材料，不是案例本身。**

## 4. 总体路线：还有哪些大步骤

### Phase 1｜问题定义与初始分类

**状态：已完成。**

完成目标、D/L/W、12类初始情境及第一次分层。

### Phase 2｜分类与案例基本单位加固

**状态：基本完成。**

完成两轮压力测试；明确Decision Atom、真实决策窗口、主体结构和叙事污染。

### Phase 3｜Decision Atom v1 实操编码测试

**状态：下一步。**

目的不是继续发明理论，而是验证：一个研究者面对真实候选案例时，能否稳定、低歧义地填写v1。

计划只取4个新样本，刻意减少政治/战争/最高层案例：

1. 职业/组织中的中层人物
2. 商业或技术中的具体决策
3. 普通个人/家庭的长期选择
4. 结果较陌生、史料较好的低叙事污染案例

重点观察：

- 字段是否能稳定填写
- 是否存在大量重复字段
- 哪些字段从不影响判断
- 同一案例换研究者是否会产生过大编码差异
- 是否仍存在结构性漏项

原则：**除非多个样本重复暴露同一缺口，否则第三轮不轻易加字段。**

### Phase 4｜准入规则 + 评分量表 v1

**状态：待开始。**

第三轮编码测试通过后，正式区分：

- 能否进入D核心库的硬门槛
- 是否值得优先研究的评分项
- 何时降级为L/W
- 背景负担、史料质量、结局熟悉度、叙事污染、多视角、迁移价值等如何计分

完成这一阶段后，才真正拥有可规模化使用的筛选器。

### Phase 5｜建立候选案例池

**状态：待开始。**

不直接搜“好书”，而按D1—D7 / N、情境坐标和人物/决策单位，有意识寻找Case Field / Episode / Atom候选。

要求控制样本偏差：

- 中国 / 世界
- 政治 / 商业 / 技术 / 职业 / 家庭 / 战争等
- 高层 / 中层 / 普通人
- 成功 / 失败 / 结果混合
- 已知结局 / 低叙事污染

并为同一决策问题寻找不同结果的对照样本，避免幸存者偏差和“历史名局”偏差。

### Phase 6｜从高分案例反推材料与书

**状态：待开始。**

每个候选案例再寻找不同材料角色：

- B：Background
- P：Protagonist / Evidence
- N：Narrative
- R：Reveal / Review

不再寻找“完美的一本书”。一个案例可以由一章背景史、传记片段、日记/书信、档案和事后研究共同组成。

### Phase 7｜小规模试运行

**状态：待开始。**

先制作和实际阅读一组小样本，而不是直接扩展到几十上百案例。

初步可考虑：

- 8—12个D案例
- 3—5个L案例
- 3—5个W案例

真实使用后复盘：代入感、背景成本、Freeze质量、迁移价值、阅读负担、书目可得性等。

### Phase 8｜扩展为长期路线图

**状态：远期。**

只有小规模试运行验证有效后，才扩展成长期案例库、书单和阅读计划。

## 6. 下一个小任务

### 第三轮压力测试：Decision Atom v1 实操编码

只取4个新样本，不追求“典型名局”，而追求不同场景下的工具可操作性。

每个样本严格按v1填写：

> 主体 → 行动权位置 → 决策窗口 → 信息集 → 现实选项 → 承诺阈值 → Stakes → D1—D7/N → 情境坐标 → 叙事污染 → 史料条件 → 是否准入D核心库

本轮的评价对象不是历史人物，而是 **v1本身**。

本轮尽量不增加新字段；如果单个样本出现特殊情况，先记“观察项”，只有重复出现才考虑升级为正式字段或模块。

## 7. 暂未解决、但不阻塞下一阶段的问题

1. **社会位置 E 问题**：高层/中层/普通人的简单三分法仍偏粗；暂不急于扩展成复杂社会分层。
2. **L/W各自的正式字段体系**：当前只定义了基本单位，尚未像D一样完成压力测试与字段设计。
3. **Contingency Activation**：何时启动已经准备好的备用方案，是否值得独立成为决策原型，暂观察。
4. **D5 Relationship State**：信任存量、相互依赖、退出成本、替代伙伴等适合作为D5专属模块，尚待更多样本验证。
5. **编码者一致性**：第三轮开始正式观察同一案例是否可能被合理编码成完全不同的结构。

本文件是本项目的**单一进展入口**，后续讨论如发生以下变化，应直接更新本笔记，而不是另起新的路线文件：

- 完成一轮压力测试；
- Decision Atom字段或分类结构发生实质变化；
- 路线阶段完成/新增/取消；
- 下一步任务改变；
- 某个暂存问题被正式解决或被放弃。

具体规范、正式字段表、候选案例清单、书目等应单独成文，本笔记只保留足够理解项目为何走到当前位置的脉络与路线。
