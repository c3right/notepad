# SEL专题｜《小老虎丹尼尔》中文动画与KASEL绘本研究及使用评估

> **状态与证据等级**：本笔记是截至2026-10-17的阶段性研究归档，不是出版方/发行方的版权鉴定或教学效果认证。公共资料与实际PDF样本已核部分单独列明；视频音轨、在售新版全文和部分书名映射仍待核。相关索引：[96册旧版A—F与新版13主题对照](./2026-10-17-sel-kasel-96-edition-crosswalk.md)。本仓库按年月归档，未来同主题新成果在根目录INDEX的“SEL教育与儿童发展”章节汇总。

## 一句话结论

《Daniel Tiger's Neighborhood》（《小老虎丹尼尔》）是以学龄前SEL为重要目标的动画，其教学关键在于“具体冲突／承认情绪／简短可记忆的策略歌曲／反复迁移”。国内“共情陪伴 KASEL”96册将独立故事归入13类儿童情绪与生活主题；已审13本扫描PDF显示，它不是简单的动画剧照集合，而是在每册添加指导、中文策略提示、情境内提问及结尾练习。**有较高的家庭SEL辅助使用价值，尤其用于情绪管理、同伴交往和挫折应对；不是覆盖CASEL五能力的完整系统课程。**

## 核心概念

- 美国CASEL的五项核心能力（CASEL 5）：自我认知 Self-awareness、自我管理 Self-management、社会认知 Social awareness、人际关系技能 Relationship skills、负责任的决策 Responsible decision-making。官方定义：https://casel.org/what-is-sel/
- 国内KASEL是本套出版物使用的教育项目与分类标签，**不等同于美国CASEL官方认证**。
- 原版核心目标年龄约2—4岁，中文绘本在成人共读条件下可适度拓展，但对年长儿童需补充更复杂的社会认知/决策活动。原制作机构：https://www.fredrogers.org/production/daniel-tigers-neighborhood/ ，PBS 家长说明：https://www.pbs.org/parents/shows/daniel/about
- 原版常将两个11分钟故事组成一个约半小时节目；国内合集常按11分钟单篇编号，故**季/集号不可直接混用**，应该以英文故事名与实际剧情为主。

## 三、13册抽样的SEL评估

| 重点样本 | 文本设计发现 | 使用要点 |
|---|---|---|
| B-14 丹尼尔生气了 | 先承认愤怒、再提出深呼吸及数到四等可执行策略 | 不把“生气”本身定为错误 |
| F-3 丹尼尔嫉妒了 | 允许嫉妒、鼓励讲述和处理 | 不以羞耻惩罚嫉妒 |
| F-1 我们的感受不一样 | 同一事件可能有不同感受 | 防止“他人一定跟我想的一样” |
| C-8 遇到困难怎么办 | 求助是合理的解决方式 | 不把独立性等同于拒绝帮助 |
| F-8 一步一步慢慢来 | 困难任务拆解，逐步尝试 | 可用于练动作和新技能 |
| A-1 独一无二的丹尼尔 | 自我特征、自我接纳 | 避免比较式表扬 |
| D-3 相同和不同 | 辨认共同点、差异、尊重 | 与不同的人相处 |
| B-6 丹尼尔想他人所想 | 在妹妹休息需要安静时理解对方需要 | 不应泛化为无条件服从 |
| B-4 考虑他人的感受 | 强化关注别人想法的策略 | “考虑他人”≠压抑自己的合理需要 |
| E-8 投票是个好办法 | 个人偏好、方案选择、表决、接受未如愿的结果 | 是少见的明确决策训练案例 |
| D-14 丹尼尔被冷落 | 父母倾听和接纳被排斥的难过，不强迫快速开心 | 可以训练表达需要/寻求支持 |
| A-4 犯错误了怎么办 | 烘焙中将无心失误与蓄意破坏区别、尝试修复 | 不用“犯错=我不好”进行教育 |
| D-1 停听指令才安全 | 以红灯停、道路/活动安全解释规则 | 仅支持有依据的安全规则，**不是任何指令无条件服从** |

**共通的教学结构**：封面/版权页→人物介绍→成人指导与“共情分享”建议→图像故事，在关键页插入简短红字家长提示→重复中文策略→末尾提问和亲子共情练习。该结构在已审13本中确实存在；不少指导提示模板化重复，个别语句过于绝对。

**证据边界**：这是基于文本和插图的**教学设计质量**判断，不能直接证明儿童参加实际学习后的效果，也不能把英语原版研究结论自动归于国内改编版。没有逐页新旧正文比对，不知道新版是否只改封面/主题。

## 四、以CASEL五能力评价96册选题

| CASEL能力 | 主要相关中文主题 | 结论/缺口 |
|---|---|---|
| 自我认知 | 建立自信心；情绪表达各册 | 能认识差异、自我接纳；需补充情绪原因及个人需要 |
| 自我管理 | 生气、害怕、自控、抗挫、适应 | **内容最强**；警惕把自控误解为听话 |
| 社会认知 | 共情、自我差异、家庭 | 有基础；需补充尊重差异及边界 |
| 人际关系技能 | 冲突、社交、分享、求助 | **内容丰富**，可用于协商、拒绝、表达及合作 |
| 负责任的决策 | 投票、犯错后修复、自控、责任 | 容易被“责任感=做家务/值日”替代，需主动练选择/后果 |

“自我管理42册、人际28册”等早先会话统计属于**把13主题强行单归一项的探索性分组**，并非课程官方能力比例，故事实际上多能力交叉，不宜直接当精确统计。

## 五、购买建议（以约3—6岁、一般家庭使用为条件）

**先买/优先看**：学会管理情绪—生气（4册）、发展冲突解决力（10册）、增强抗挫力（8册）、发展共情力（6册），共28册；如需增强自我认知，再加建立自信心（8册），共36册。该次序不是“重要性”绝对排序。

**按需补充**：建立社交力（遭冷落/拒绝特别实用）、害怕（有相关困扰）、提升自控力（需核其规则教育边界）、提升适应力（入园、睡觉、看医生、如厕）。分享力、学会担当与发展责任感可以按孩子当前需要选择，不必为凑96册全部买齐。

**单个故事使用法**：孩子遇到实际情境→共读时先描述感受→看对应动画与策略句→用简单假设题练习“有哪几种办法、会发生什么”→在现实小场景实际使用→数日后复习。不要以“像丹尼尔一样乖”为目标；优先训练儿童自己判断、表达与求助。

## 六、尚需验证

1. 商家是否真的允许按照13主题单独购买？旧套按A-F每套16本销售，新商品宣传图的主题分组不自动等于可独立售卖SKU。
2. 上架实物和扫描PDF的**文字、指导页、练习页是否有实质修改**；需一本新版同标题完整内页对比。
3. 96个KASEL视频的逐条目录、来源授权、激活有效性、地区/设备限制以及是否保留策略歌曲。
4. 2015年授权130个11分钟故事的**官方逐集清单**；2019以后流传的国语130集含美国第三季片段，不能当成2015合同的原始清单。
5. 96册版本对应表的低置信条目，需要旧版未提供PDF内页或新版实际试看补证。
6. 后续更系统的儿童SEL素材研究（包括港台繁体绘本）建议在本主题增设独立笔记并从INDEX主题章节关联，保留各自版本与核验日期。
