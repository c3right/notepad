## 一句话结论

已**逐一查看46册旧版PDF的物理第4页（正文印刷页码通常是2）**的说明、共情分享及阅读建议。按照[SEL应用总规则](./2026-10-26-sel-foundational-purpose-autonomy-guardrails.md)，7册成人提示有需要修订的绝对化或标签化措辞，12册需要补充适用条件；其余27册没有发现与总规则的实质冲突。**不等于46本故事或新版纸书均已逐页核验；更不等于教学效果经实证验证。**

## 7册：不宜原样照搬的表述

| 旧版PDF | 风险与原指南主张 | 家长替代表述/原则 |
|---|---|---|
| `D-15` 我来帮助你 | 把内向/谨慎与无法融入集体关联，可能污名化正常气质 | 帮助孩子在愿意时练习求助与交往；慢热、独处和少数朋友都可以 |
| `D-16` 好朋友互相帮助 | 与D-15复用同伴关系说明，将内向/孤僻/自我中心并列为风险 | 不以外向衡量发展；朋友互助须出于意愿，也可以拒绝 |
| `B-6` 丹尼尔想他人所想 | 用‘无论做什么事，都要考虑他人感受’概括共情，且强调调整自己的行为 | 理解别人并表达自己的需要；理解不等于答应或让步 |
| `B-4` 考虑他人的感受 | 与B-6相同的绝对化共情模板，缺少明确个人边界 | ‘我知道你难过，我也想……；我们能商量吗？’ |
| `F-11` 心中有他人 | 复用‘无论做什么事，都要考虑他人感受’模板 | 考虑他人时保留自己安全、物品与身体边界 |
| `B-16` 再试一次 | 反复强调‘不要因失败而放弃’、‘反复练习获得成功’ | 可以再试、换方法、求助、休息或之后再试 |
| `B-15` 丹尼尔学接球 | 与B-16相同抗挫模板，将持续练习设为优先结果 | 尊重儿童意愿和负荷；休息不等于失败 |

## 12册：有条件使用，需补充边界

| 旧版PDF | 需要注意的原指南方向 | 家长使用时补充 |
|---|---|---|
| `C-8` 遇到困难怎么办 | 导言把挫折承受能力弱与未来发展受损相联系，易增加家长焦虑 | 不用评判孩子‘抗挫力弱’，具体支持表达难过与求助 |
| `C-1` 丹尼尔受挫了 | 同一挫折应对模板带有‘被挫折击垮’等灾难化叙述 | 遇到困难先陪伴，允许暂时停止，不做未来人格推断 |
| `F-3` 丹尼尔嫉妒了 | 提示家长不要急于介入嫉妒引起的纠纷 | 仅限安全、平等的小摩擦；有抢夺、伤害或排斥成人应及时介入 |
| `F-4` 感到嫉妒说出来 | 同F-3，倾向让儿童自行解决嫉妒后的纠纷 | 允许儿童协商，但不把保护边界与解决纠纷全部交给幼儿 |
| `E-7` 当选择不一样时 | 把‘少数服从多数’作为集体选择方法，未限定表决范围 | 仅用于选游戏等公共小事；身体同意和私人财物不能投票决定 |
| `E-8` 投票是个好办法 | 与E-7相同的投票模板 | 让孩子体验选举，但少数意见、拒绝和个人权利仍需保护 |
| `A-5` 生气生气我很生气 | 推荐孩子‘大声’说出生气；可能被理解成朝人吼叫 | 可以清楚有力地说‘我很生气’，不要对人吼叫、威胁或伤害 |
| `A-6` 生气大声说出来 | 与A-5相同的‘大声表达生气’指南 | 保留表达情绪的权利，同时区分说感受与伤害别人 |
| `E-9` 特别的野餐 | 建议把坏事转到积极的一面，容易过快要求积极化 | 先接受失望；等孩子愿意后再讨论还有哪些选择 |
| `E-10` 不一样的生日蛋糕 | 与E-9相同的改变认知、调节情绪模板 | 先接住难过与遗憾，重看事情的角度只是可选方法 |
| `D-14` 丹尼尔被冷落 | 引导被冷落的孩子寻找喜欢的事缓解伤心，但未涉及持续排斥 | 偶发冷落可以自我安慰；反复或针对性排斥要由家长与老师介入 |
| `E-2` 道歉是第一步 | 建议引导闯祸的孩子说‘对不起’，易被误用为机械道歉 | 先理解影响、道歉可由成人示范，再选择修理、归还、清理等实际补救 |

## 使用规则

- **不用修改或裁剪旧版PDF**：正常享受故事；阅读前仅由成人查看上表替代建议，不把“共情分享”逐条念给儿童。
- 若指南建议某件事“必须/任何时候/无论做什么”，先核实它是否属于**安全底线、共同生活安排、个人合理偏好**。三类适用的成人权限不同。
- 个人身体同意、私人财物、合理拒绝不能靠投票或“考虑别人感受”取消；同伴相处中出现持续排斥、伤害、霸凌苗头须成人提供保护与协调。
- 允许儿童有嫉妒、愤怒、失落，也允许尝试、换方法、休息、求助；不以更听话、更少哭、更爱交际评判SEL成功。
- **版本限制**：这一轮审查的是**旧版PDF第4页**，不是新版13主题纸书的家长指南。如新版文字变动需复核；旧版13主题对应有个别工作映射待核。未上传、公开、复制任何PDF或其扫描图像。
