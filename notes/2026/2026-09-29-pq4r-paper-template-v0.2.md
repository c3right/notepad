# PQ4R“可见阅读”纸面模板 v0.2

## 一句话结论

纸面模板不应把 PQ4R 六步分别画成六个大格子。

更合理的是：

> **章级启动页 + 阅读单元正反页 + 极简 Review 日志。**

其中：

- 章级启动页承载 Reading Intent Gate 与 Preview；
- 阅读单元正面是**开卷面**：Question、Read 的答案骨架、一次 Reflect；
- 阅读单元背面是**闭卷面**：Recite、Review 校准；
- Read 阶段大量临时标记尽量留在原书页边，不重复抄入笔记；
- 长期真正保存的最小认知产物，压缩成 **Q / Model / Recall / Gap** 四件套。

这四件套就是 Minimum Viable Reading Record。

---

# 1. 设计原则

## 1.1 模板必须服从认知状态，而不是服从六个字母

PQ4R 实际上存在三种不同状态：

### 进入文本前

- Preview
- Question

### 开卷理解

- Read
- Reflect

### 闭卷提取

- Recite
- 后续 Review

如果把这些动作混在同一视觉区域，容易发生：

- Recite 时偷看到答案；
- Read 时过早做 Reflect；
- Review 退化成浏览旧笔记。

所以纸面首先要分离：

> **开卷区 vs 闭卷区**

而不是先问：

> “P/Q/R/R/R/R 各占多少格？”

---

## 1.2 过程痕迹与长期产物分开

过程痕迹包括：

- Q1 / Q2 页边标记；
- ?；
- !；
- ↔；
- 临时圈词；
- 回读位置。

这些是：

> **导航工具**

不是长期学习成果。

长期值得保留的是：

- 核心问题；
- 最终形成的知识模型；
- 第一次闭卷重建；
- 两者之间的差距与未解决点。

所以：

> **不要把“所有过程都留下”误解成可见阅读。**

可见阅读真正要留下的是：

> **可见的认知产物和可见的校准痕迹。**

---

## 1.3 默认模板只为 Mode A：学习型阅读设计

Reading Intent Gate：

- Mode A 学习型 → 使用完整模板；
- Mode B 研究型 → 通常只使用章级启动页 + 开卷面；
- Mode C 扫描型 → 通常只使用 Preview / Question / Selective Read。

因此模板本身不强迫所有文本执行完整 PQ4R。

---

# 2. Minimum Viable Reading Record：Q / Model / Recall / Gap

每个值得完整执行 PQ4R 的阅读单元，最终至少留下四样东西。

> ## **Q — Model — Recall — Gap**

这不是新的学习步骤，而是对现有 PQ4R 产物的压缩。

---

## 2.1 Q：Question

记录：

> **这个阅读单元最核心的问题是什么？**

默认：

- 1 个核心 Q；
- 真正核心 / 困难内容最多再加 1 个 Q+。

Q 是整个记录的锚点。

如果未来重新打开这页，第一眼就应知道：

> 我当时为什么读这一段？

---

## 2.2 Model：开卷形成的最佳理解模型

Model 来自：

> Read + Reflect

它不是摘要全文。

它应回答：

> **作者最终怎样回答 Q？这些信息是什么结构？**

形式可以是：

- 极简答案骨架；
- 因果链；
- 比较表；
- 分类树；
- 时间 / 过程图；
- 一段极短解释。

默认应尽量结构化，而不是长段落。

例如：

早期采用  
→ 学习 / 协调收益增加  
→ 后续采用收益增加  
→ 转换成本提高  
→ 路径强化

Model 是：

> **开卷条件下，你目前能建立出的最佳理解。**

---

## 2.3 Recall：第一次闭卷重建

Recall 来自 Recite。

要求：

> **不看 Model，从记忆中重新回答 / 重建。**

普通单元可以只做：

- 回答 Q；
- 简单重建结构。

核心单元再加：

- 解释一个关键 Why / How。

重要规则：

> 第一次闭卷错误、空白、遗漏不要擦掉。

Recall 不是“最后正确答案”。

它是：

> **第一次真正暴露出来的内部模型。**

---

## 2.4 Gap：Model 与 Recall 的差距

Review-核完成后记录：

> **我哪里记错了、漏了、关系没连上？还有什么仍未解决？**

Gap 可以包含：

- △ 漏了一环；
- × 概念混淆；
- ✓? 虽答对但不确定；
- 未解决问题；
- 需要以后核验的边界。

例如：

> Gap：闭卷结构漏掉“转换成本上升”；“路径依赖是否必然低效率”仍未解决。

Gap 是整个记录里很重要但常被传统笔记忽略的一项。

因为它直接回答：

> **下一次 Review 应该重点提取什么？**

---

# 3. 为什么 MVRR 不要求保存 Preview 和全部 Read 痕迹

Preview 和 Read 都很重要。

但它们更多是：

> **scaffolding**

而不是每个阅读单元长期保存的核心知识。

因此：

- Preview 只在章级保留一次；
- Read 的 Q# / ? / ! / ↔ 主要留在书上；
- 不要求把这些标记再次抄进笔记。

否则会发生大量低价值重复劳动。

真正长期留下：

> **Q / Model / Recall / Gap**

就已经能证明：

1. 你带着问题进入文本；
2. 你形成了理解；
3. 你真正脱离原文提取过；
4. 你核对过自己的理解偏差。

这比“六步每步都有一个格子”更接近真实学习。

---

# 4. 模板总体结构

默认使用三层纸面结构：

## Layer A：章级启动页

一章一次。

承载：

- Reading Intent Gate；
- Preview；
- 阅读单元划分；
- 问题胚芽。

## Layer B：阅读单元正反页

每个重要阅读单元一张纸的正反面，或笔记本中两个不同时可见的页面。

### 正面

> **OPEN BOOK**

承载：

- Q；
- Read 答案骨架 / 定位；
- 一个 Reflect 动作；
- Model。

### 背面

> **CLOSED BOOK**

承载：

- 重复写一次 Q；
- Recall；
- Gap；
- Review log。

这种前后分离的最大优点：

> **翻到背面以后，开卷答案物理上不可见。**

Recite 不再依赖“我尽量不偷看”。

## 5.1 这一页不要出现

- 大段正文摘要；
- 完整答案；
- 复杂知识图；
- 详细批判。

如果这一页写满很多知识内容：

> Preview 已经过重。

# 7. Read 阶段什么写在书上，什么写在纸上

这是降低负担的关键。

## 7.1 书页上

第一遍只留导航：

- Q1 / Q2；
- ?；
- !；
- ↔；
- 圈关键术语。

极难文本第一遍甚至只：

- Q#；
- ?；
- !。

---

## 7.2 纸上

第一遍不急着写。

完成一次阅读单元后，定向回读时才写：

- Q 对应页码；
- 极简答案骨架；
- 必要证据定位。

也就是说：

> **书页负责定位，笔记纸负责压缩。**

不要两边重复记录同一句话。

---

# 8. Reflect 在纸面上的最新规则

Reflect 区不画四个大框。

只画：

> □ 联  □ 构  □ 释  □ 检

然后一块统一空白。

原因：

> 如果纸面预先给四个格子，人会天然产生“填满它们”的压力。

而当前协议已经明确：

### 普通阅读单元

> 只选一个。

### 核心 / 困难单元

> 最多两个。

默认不知道选什么：

> 选“构”。

这样模板本身不会诱导过度加工。

---

# 9. 阅读单元背面：CLOSED BOOK

当开卷面处理完成后：

> **翻页 / 翻面。**

正面的 Model 不再可见。

背面顶部重复一次 Q。

这是少量但值得的重复，因为它物理上保证了真正 retrieval。

推荐：

```
┌─────────────────────────────────────┐
│ CLOSED BOOK                         │
│                                     │
│ Q                                   │
│ __________________________________  │
│ Q+ _______________________________  │
├─────────────────────────────────────┤
│ RECALL                              │
│                                     │
│ ① 答：                              │
│ __________________________________  │
│                                     │
│ ② 构：                              │
│ __________________________________  │
│                                     │
│ ③ 释（核心单元才做）：               │
│ __________________________________  │
├─────────────────────────────────────┤
│ REVIEW — 核                         │
│ 答  □✓ □✓? □△ □×                   │
│ 构  □✓ □✓? □△ □×                   │
│ 释  □✓ □✓? □△ □×                   │
│                                     │
│ GAP                                 │
│ __________________________________  │
├─────────────────────────────────────┤
│ REVIEW LOG                          │
│ 日期      答   构   释   Next       │
│ ______   ___  ___  ___  ______      │
│ ______   ___  ___  ___  ______      │
└─────────────────────────────────────┘
```

---

# 10. Recite 在模板中不应默认写满“答—构—释”

为了长期可执行：

## 普通单元

背面默认只做：

> **答 + 简构**

“释”留空没有问题。

## 核心 / 困难单元

才做：

> **答 + 构 + 释**

模板必须允许空白。

空白不代表执行失败。

如果模板强迫每格都写：

> 模板正在吞噬阅读。

---

# 11. Review 在模板中只占很小空间

Review 已经被收敛成：

> **核—隔—提**

所以不需要大段“复习总结区”。

纸面只需：

1. 第一次核对状态；
2. Gap；
3. 后续几次 Review 日志。

间隔后的“提”：

> 直接在草稿纸 / 另一张空白纸上再次答—构—释。

不必每次都把全文重新誊写回原始笔记。

原始模板只记录：

> 日期 + ✓ / △ / × + Next。

这样长期维护成本很低。

---

# 12. Minimum Viable Reading Record 的完成判据

一个阅读单元如果最终留下：

## Q

> 我到底在解决什么问题？

## Model

> 开卷后我形成的最佳结构是什么？

## Recall

> 闭卷后我真正能重建出什么？

## Gap

> 二者之间差在哪里？还剩什么问题？

那么：

> **即使 Read 的页边符号后来不再看，这个阅读单元仍然留下了足够完整的学习证据。**

这就是 Minimum Viable Reading Record。

# 13. 一个完整示例

假设阅读单元：

> 路径依赖的自我强化机制

## 正面：OPEN BOOK

### Q

> 哪些机制使路径依赖自我强化？

Q+：

> 为什么早期很小的优势可能不断扩大？

### Read 骨架

- p.83–86
- 学习效应
- 协调效应
- 适应性预期
- 沉没成本
- increasing returns

### Reflect

勾：

> ☑ 构

写：

早期采用  
→ 学习 / 协调收益增加  
→ 后续采用收益增加  
→ 转换成本增加  
→ 路径强化

### Model

> 过去选择并不是简单“影响现在”，而是改变后续行动者面对的收益与成本结构，从而产生自我强化。

---

## 背面：CLOSED BOOK

### Q

> 哪些机制使路径依赖自我强化？

### Recall

答：

> 学习效应、协调效应、适应性预期、沉没成本。

构：

早期采用  
→ 收益增加  
→ 继续采用  
→ 路径锁定

释：

> 早期选择提高继续沿用原路径的收益，所以小优势会被正反馈放大。

### Review-核

答 ✓  
构 △  
释 ✓

### Gap

> 结构漏掉“转换成本增加”；仍不确定路径依赖是否必然意味着低效率。

这四部分已经构成完整 MVRR。

---

# 14. 三种密度模式

模板不要规定“一单元必须占一整张 A4”。

按内容密度调整。

## Light

适合简单内容：

- 半页；
- Q；
- 简单 Model；
- Micro Recite；
- Gap。

## Normal

默认：

> 一阅读单元 = 一张纸正反面，或笔记本前后两个页面。

## Heavy

真正困难 / 核心内容：

- 正面允许 Model 展开；
- 背面完整答—构—释；
- 必要时增加附页。

原则：

> **让内容决定空间，而不是让模板决定内容。**

---

# 15. A4、A5 与活页本

## 最适合逻辑本身的形式

> **活页纸正反面**

因为：

- 正面开卷；
- 翻面自然闭卷；
- 容易按章节重新组合；
- 难单元可以多加一张。

## A5 笔记本

也可行。

规则：

> 开卷页和闭卷页不要同时出现在一个展开面。

最好：

- 一页 Open；
- 翻页后下一页 Closed。

## A4

适合：

- 图表多；
- 理论结构复杂；
- 需要较大机制图。

模板本身与纸张尺寸无关。

---

# 16. 防止“方法吞噬阅读”的五条硬规则

## 规则 1

> 一个阅读单元默认只有一个 Q，最多 Q+。

## 规则 2

> Reflect 默认只选一个动作。

## 规则 3

> Read 页边符号不复制到笔记。

只把最终答案骨架压缩到纸面。

## 规则 4

> 普通 Recite 只做答 + 简构。

不强制释。

## 规则 5

如果发现自己：

- 花大量时间美化笔记；
- 重复抄写原文；
- 为了填满格子制造联想；
- 笔记时间开始接近阅读本身；

就立即：

> **合并阅读单元 / 降级 Reflect / 缩短 Recite。**

纸面模板的目标不是完整，而是：

> **以最低成本留下足够的认知证据。**

# 17. 最终模板与 PQ4R 的对应关系

| PQ4R | 主要纸面位置 | 是否长期保留 |
|---|---|---|
| Reading Intent Gate | 章级启动页 | 是 |
| Preview | 章级启动页 | 是，但极简 |
| Question | 单元正面 + 背面重复 | 是 |
| Read | 主要在书页标记；正面只留答案骨架 | 书页痕迹可不长期维护 |
| Reflect | 单元正面，一个动作 | 是 |
| Recite | 单元背面 | 是，保留第一次痕迹 |
| Review | 背面 Gap + 日志 | 是，但非常轻 |

# 18. 当前真正的“可见阅读”定义

旧的直觉可能是：

> 每一步都留下纸面证据。

现在应修正为：

> **关键认知状态留下可检查产物，辅助过程只在需要时留下临时索引。**

因此一个第三人真正应该看见的不是：

- 你划了多少线；
- 写了多少问号；
- 是否六格都填满；

而是：

> 你提出了什么问题；  
> 你最终怎样理解；  
> 你闭卷时实际能重建多少；  
> 你发现自己的理解哪里有缺口。

这才是“可见阅读”的核心。

---

# 19. 下一阶段：真实负载测试

模板到这里已经足够进入真实使用。

下一阶段不应继续添加字段。

应该拿真实文本测试：

1. 一章历史叙事；
2. 一章理论性社科；
3. 一章高认知负荷技术 / 哲学文本。

重点记录：

- 一个单元实际耗时；
- Reflect 最常选择哪一个；
- 哪些栏经常空白；
- 哪些栏总觉得空间不够；
- 一周后 Review 时哪些记录真正有用；
- 是否出现“为了模板而阅读”的感觉。

真实使用后再决定删什么，而不是继续加什么。
