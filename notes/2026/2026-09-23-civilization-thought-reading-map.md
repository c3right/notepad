## 原典与核心文本

1. **孔子｜《论语》**
   - 推荐版本：杨伯峻《论语译注》，中华书局。
   - 使用：全文读。
   - 提示：有注有译，适合直接入门；抓“仁、礼、君子、德治、学”。

2. **老子｜《老子》**
   - 推荐版本：陈鼓应《老子今注今译》，商务印书馆。
   - 使用：可全文；若控制进度，先读约20个核心章。
   - 提示：适合作为首读本。

3. **韩非｜《韩非子》**
   - 首读推荐：**张觉等《韩非子译注》，上海古籍出版社。**
   - 研究查阅：陈奇猷《韩非子新校注》，上海古籍出版社。
   - 使用：重点读《二柄》《定法》《难势》《五蠹》《显学》，有余力加《孤愤》《说难》。
   - 提示：第一次以张觉本为主；训诂、校勘疑义再查陈奇猷。

4. **朱熹｜《四书章句集注》**
   - 推荐版本：朱熹《四书章句集注》，中华书局整理本。
   - 使用：《大学章句》《中庸章句》全文，再选读《论语集注》《孟子集注》。
   - 提示：重点看儒家如何被注释、教材化和制度化。

5. **印度思想｜《奥义书》**
   - 推荐版本：黄宝生译《奥义书》，商务印书馆。
   - 使用：重点读《大森林》《歌者》《自在》《由谁》《伽陀》等。
   - 提示：先掌握“梵、我、业、轮回、解脱”。

6. **印度思想｜《薄伽梵歌》**
   - 推荐版本：黄宝生译《薄伽梵歌》，商务印书馆。
   - 使用：重点读第2、3、4、6、11、12、18章。
   - 提示：与《奥义书》连读，理解行动、责任与解脱。

7. **早期佛教｜《经集》**
   - 推荐版本：郭良鋆译《经集》，中国社会科学出版社。
   - 使用：选读。
   - 提示：作为早期佛教思想的主要入口。

8. **早期佛教｜《法句经》**
   - 推荐版本：黄宝生《巴汉对勘〈法句经〉》，中西书局。
   - 使用：读约一半至全文。
   - 提示：普通读者主要读现代中文部分即可。

9. **早期佛教补充短经**
   - 文本：《转法轮经》《无我相经》《迦罗摩经》。
   - 使用：全文。
   - 提示：分别理解四谛、无我以及判断与权威问题。

10. **犹太传统｜《摩西五经》**
    - 推荐版本：《和合本修订版 / 和合本2010》。
    - 使用：《创世记》1—3、12—22；《出埃及记》1—24；《申命记》5—6、12、15—17、30。
    - 提示：不要求通读五经；抓“创造、盟约、律法、共同体”。

11. **耶稣｜《新约》福音书**
    - 推荐版本：《和合本修订版》。
    - 使用：《马可福音》全文；《马太福音》5—7章。
    - 提示：先读福音，再进入保罗。

12. **保罗｜《加拉太书》《罗马书》**
    - 推荐版本：《和合本修订版》。
    - 使用：《加拉太书》全文；《罗马书》1—8、12—13章。
    - 提示：抓“律法、信、恩典、称义、普世共同体”。

13. **奥古斯丁｜《上帝之城》**
    - 推荐版本：吴飞译《上帝之城：驳异教徒（修订译本）》，上海三联书店。
    - 使用：第一卷；第四—五卷选；第十四卷选；第十九卷重点。
    - 提示：不全文硬啃；抓“两城、原罪、意志、和平”。

14. **阿奎那｜《论法律》**
    - 推荐版本：杨天江译《论法律》，商务印书馆。
    - 使用：《神学大全》I-II，问题90—97。
    - 提示：不必购买整套《神学大全》；先有亚里士多德和自然法背景。

15. **路德｜宗教改革三篇**
    - 推荐版本：《路德三檄文和宗教改革》，上海人民出版社。
    - 使用：《论基督徒的自由》全文；另外两篇选读。
    - 提示：先了解赎罪券、教皇权威、因信称义和宗教改革背景。

16. **伊斯兰｜《古兰经》**
    - 推荐版本：马坚译《古兰经》。
    - 使用：首次重点读第1、2选、5选、12、19、24选、49、55、96、112章。
    - 提示：区分麦加时期与麦地那时期主题。

17. **伊斯兰｜圣训**
    - 参考版本：《布哈里圣训实录全集》，商务印书馆。
    - 使用：按主题查阅，不建议为本路线全文通读。
    - 提示：需要理解先知传统、司法、商业和社会规范时再查。

18. **安萨里｜《迷途指津》**
    - 推荐版本：康有玺译《迷途指津；致孩子》，宗教文化出版社。
    - 使用：全文。
    - 提示：是进入安萨里思想最合适的原典入口。

19. **安萨里｜《圣学复苏》相关**
    - 可用版本：《圣学复苏精义》。
    - 使用：选读知识、行为、心灵、德性部分。
    - 提示：属整理 / 节编性质，不是严格完整全译本。

20. **亚里士多德｜《尼各马可伦理学》**
    - 推荐版本：廖申白译注，商务印书馆。
    - 使用：第I、II、V、VI、X卷。
    - 提示：抓“幸福、德性、实践智慧、正义”。

21. **亚里士多德｜《政治学》**
    - 推荐版本：吴寿彭译，商务印书馆。
    - 使用：第I、III、IV、VII卷选。
    - 提示：与《尼各马可伦理学》连读。

22. **西塞罗｜《论共和国》《论法律》**
    - 首选：王焕生译《论共和国 论法律》，中国政法大学出版社。
    - 备选：商务印书馆现行相关合刊译本。
    - 使用：《论共和国》I—III；《论法律》I—III。
    - 提示：抓“共和国、公民义务、自然法、混合政体”。

23. **洛克｜《政府论》下篇**
    - 推荐版本：叶启芳、瞿菊农译，商务印书馆。
    - 使用：1—5、7—9、11—14、18—19章。
    - 提示：抓“自然权利、财产、同意、政府边界、抵抗权”。

24. **洛克｜《论宗教宽容》**
    - 推荐版本：吴云贵译，商务印书馆。
    - 使用：全文。
    - 提示：与《政府论》下篇合读。

25. **孟德斯鸠｜《论法的精神》**
    - 推荐版本：许明龙译，商务印书馆。
    - 使用：I—III、V选、XI尤其第6章、XIX选、XX—XXI选。
    - 提示：不要只记“三权分立”，重点是法与政体、风俗、经济、历史条件的关系。

26. **亚当·斯密｜《道德情操论》**
    - 推荐版本：商务印书馆集体译本（蒋自强主持）。
    - 使用：第一、第三、第六卷选。
    - 提示：先理解“同情、公正旁观者、道德判断”。

27. **亚当·斯密｜《国富论》**
    - 推荐版本：郭大力、王亚南译《国民财富的性质和原因的研究》，商务印书馆。
    - 使用：第一篇1—3章、第8章选；第四篇第2章；第五篇相关选段。
    - 提示：与《道德情操论》合读，不建议首次全文通读。

28. **马克思｜《共产党宣言》**
    - 推荐版本：人民出版社 / 中央编译系统通行译本。
    - 使用：全文。
    - 提示：先建立资产阶级、无产阶级、世界市场和阶级关系的总体图景。

29. **马克思｜桥接文本**
    - 文本：《雇佣劳动与资本》《工资、价格和利润》。
    - 使用：全文或主体部分。
    - 提示：为《资本论》预先建立工资、劳动力、利润、剩余价值概念。

30. **马克思｜《资本论》第一卷**
    - 推荐版本：人民出版社中央编译系统校订本。
    - 使用：第1、4、6—10、15、23—24章。
    - 提示：不要在第1章长期卡住；第一次不完全理解价值形式可以继续。

## 核心导读工具

31. **冯友兰《中国哲学简史》**
    - 推荐版本：赵复三译，中华书局。
    - 用途：老子、法家、宋明理学、朱熹等中国思想背景。
    - 使用：地图型查阅，不要求全文通读。

32. **休·汉密尔顿《印度哲学祛魅》**
    - 推荐版本：王晓凌译，译林出版社新版。
    - 用途：《奥义书》《薄伽梵歌》和佛教的统一背景。
    - 使用：相关章节先于原典。
    - 定位：核心必备导读之一。

33. **John Riches《〈圣经〉纵览》**
    - 推荐版本：梁工译，外语教学与研究出版社。
    - 用途：《摩西五经》、福音书、保罗及基督教传统背景。
    - 使用：重点理解文本形成、正典、解释共同体和文化影响。

34. **赵敦华《西方哲学简史》**
    - 推荐版本：北京大学出版社修订版 / 第2版。
    - 用途：亚里士多德、奥古斯丁、阿奎那等。
    - 使用：当索引型工具书，按人物查对应章节。

35. **Jonathan Barnes《亚里士多德的世界》**
    - 推荐版本：史正永、韩守利译，译林出版社新版。
    - 用途：《尼各马可伦理学》《政治学》之前。
    - 使用：重点读“其人其著、哲学背景、实践哲学、后世影响”。

36. **Christopher J. Berry《亚当·斯密：牛津通识读本》**
    - 推荐版本：李瑶光译，译林出版社，2025。
    - 用途：连接《道德情操论》和《国富论》。
    - 使用：篇幅不大，可完整读。

## 按需辅助 / 深入工具

37. **John Dunn《洛克：牛津通识读本》**
    - 推荐版本：方尚芩译，译林出版社。
    - 用途：洛克政治思想背景。
    - 使用：可借阅，不必一定收藏。

38. **秦惠彬《伊斯兰文明》**
    - 推荐版本：福建教育出版社版。
    - 用途：穆罕默德、早期阿拉伯社会、《古兰经》及伊斯兰共同体背景。
    - 使用：只读前部相关章节。

39. **赵敦华《基督教哲学1500年》**
    - 推荐版本：商务印书馆修订版。
    - 用途：深入奥古斯丁、阿奎那及中世纪哲学。
    - 使用：第一轮不必购买；真正深入时再用。

## 整体使用原则

40. **第一次阅读只抓四层**
    - 作者 / 传统面对什么核心问题；
    - 核心答案是什么；
    - 使用了哪些关键概念；
    - 思想后来怎样进入制度和社会现实。

41. **采用 70% 规则**
    - 个别句子不懂：标记，继续。
    - 核心概念反复不懂：查简明定义。
    - 不知道作者为什么讨论这个问题：暂停原典，回导读。

42. **推荐顺序**
    - 中国：孔子 → 老子 / 韩非 → 朱熹
    - 印度：奥义书 / 薄伽梵歌 → 佛教
    - 犹太—基督教：摩西五经 → 耶稣 / 保罗 → 奥古斯丁 → 阿奎那 → 路德
    - 伊斯兰：古兰经 → 安萨里
    - 希腊—罗马：亚里士多德 → 西塞罗
    - 现代社会：洛克 → 孟德斯鸠 → 斯密 → 马克思

## 版本说明

- 本页优先记录适合第一次认真阅读的中文版本，不等同于每一种文本的最严格学术校本。
- 版本、印次和 ISBN 可能变化；实际购买时以出版社版权页为准。
- 研究性阅读需要时，再升级到校勘本、原文对照本或专业注释本。
