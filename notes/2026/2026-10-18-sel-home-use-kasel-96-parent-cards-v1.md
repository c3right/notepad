# 家长拿来就能用：KASEL 96册＋中文配套视频

> **状态与证据**：用户决定购买新版**13主题96册全套纸质绘本**；用户向官方客服询问后获答复“配套96个视频是中文版”。这属于**用户转述的客服答复**，并非实物/音轨的独立验证；尚未证实每集普通话对白、策略歌曲为中文、激活及有效期。此前**实读的是旧版13册PDF**，而非新版实物；下列新版书名通过现有工作表对应，完整新旧逐页比较仍待验收。

## 一、总路线：96册是书架，不是96节课

**优先使用纸质书自然共读；视频可选；在生活中由成人先示范。** 儿童喜欢哪个故事、最近经历什么，就翻哪个，不按封面的13主题或96个视频排进度。首次阅读只是讲故事，不必提问。孩子愿意时再用一个简单句子，比如“你生气是可以的，但我会阻止打人”。哭闹最激烈时先照顾安全、帮助安定，平静后再讨论。

- **丹尼尔/KASEL**：需要明确说法和可试方法时优先，例如求助、安抚、犯错后的补救。
- **布鲁伊中文版**：已经有合适的屏幕时间时，适度看游戏和人际互动；不强迫从动画中提炼标准答案。
- **弗洛格、阿尔菲、波西和皮普等文学**：长期自然共读，保留阅读乐趣，不要求变成SEL练习题。
- **其他简繁体专题绘本**：仅在既有96册确有空缺、且孩子有需要时再选，避免同主题超配。

**家长的最短操作**：挑一本—正常读—孩子喜欢则复读—现实有相似情境时借用一句话。无每日计划，无测验，无必须看视频要求。

## 三、首批13张家长卡：基于已审旧版，不假装新书已读

**卡片中的家长话术和活动是本研究的实践建议，不是动画原句或出版方引文。** 最先使用前六张即可；其余按需拿出来。每张仅“书—一句话—可选动作—注意”。

### A. 3岁半可以优先使用的六张

**01 生气｜新版《不能玩，很生气》；旧B-14《丹尼尔生气了》**  
一句话：“你还想玩，现在玩不了，很生气。我陪你，不能打人。”  
可选：平静时试吹气或慢慢数四下，孩子不愿就不用。  
**注意**：深呼吸不是制止哭闹的命令，生气本身不是错。

**02 求助｜新版《遇到困难怎么办》；旧C-8同名**  
一句话：“这件事有点难，你想我帮哪一步？”  
可选：让孩子对难搭的积木选“自己试、一起做、稍后再试”。  
**注意**：求助不等于软弱；其英文动画逐集对应仍有待核项。

**03 把事情分小步｜新版《一步一步慢慢来》；旧F-8同名**  
一句话：“先做一小步，可以慢慢来。”  
可选：穿鞋、整理物品时只完成一个小动作。  
**注意**：不是“不准放弃”，允许休息、换方法。

**04 被冷落｜新版《被冷落，好难过》；旧D-14《丹尼尔被冷落》**  
一句话：“没有人带你玩，难过可以告诉我，我会帮忙。”  
可选：玩偶演练“我也想加入”“现在还不想一起玩”。  
**注意**：不要求被拒绝的孩子独自化解；欺负需要成人保护。

**05 犯错与补救｜新版《犯错误了，怎么办》；旧A-4《犯错误了怎么办》**  
一句话：“不小心做错了，我们看看怎么补救。”  
可选：模拟不小心弄洒水，然后一起擦干。  
**注意**：区分无意失误与蓄意伤害；不强迫机械道歉。

**06 感受不同｜新版《我们的感受不一样》；旧F-1同名**  
一句话：“你觉得好玩，别人可能觉得害怕，两个人可以不一样。”  
可选：两人各选自己喜欢的故事，不争“谁选得对”。  
**注意**：理解别人并不意味着必须同意对方。

### B. 其他七张：仍可现在读，按需要使用

**07 自我接纳｜新版《独一无二的丹尼尔》；旧A-1同名**  
一句话：“你有自己的样子和喜欢的事。”  
可选：说说喜欢的游戏或本领。  
**注意**：不通过“你比别人优秀”塑造自信。

**08 尊重差异｜新版《相同与不同》；旧D-3《相同和不同》**  
一句话：“我们有一样的地方，也有不一样的地方。”  
可选：比较玩偶的共同点和差异。  
**注意**：不能要求儿童必须喜欢所有差异。

**09 嫉妒｜新版《丹尼尔嫉妒了》；旧F-3同名**  
一句话：“别人有，你也想要，可能有点嫉妒。”  
可选：孩子自发说类似感受时认真听。  
**注意**：不要羞辱嫉妒，也不要允许因此抢夺。

**10 他人的需要｜新版《丹尼尔想他人所想》；旧B-6同名**  
一句话：“妹妹在休息，你想玩，我们找个大家都舒服的方法。”  
可选：娃娃睡觉时用小声活动或换地方玩。  
**注意**：不能推论为儿童任何时候都必须安静服从。

**11 考虑他人｜新版《考虑他人的感受》；旧B-4同名**  
一句话：“你和朋友都想玩，可以问问对方怎么想。”  
可选：玩偶演示“你愿意吗？”和尊重拒绝。  
**注意**：共情不等于单方面让步。

**12 安全规则｜新版《停，听指令，才安全》；旧D-1《停听指令才安全》**  
一句话：“路口先停，是为了看清有没有危险。”  
可选：室内玩红灯停、绿灯走；真实道路仍由成人保护。  
**注意**：安全规则不等于对任何成人要求都必须无条件服从。

**13 共同决定｜新版《投票是个好办法》；旧E-8同名**  
一句话：“大家想法不同，有些小事可以一起投票决定。”  
可选：两首安全合适的歌由全家选择。  
**注意**：不以投票取消个人身体界限或迫使孩子交出私人物品。

## 四、纸书和96个视频怎么配合

**只读绘本：完全足够。** 若孩子看了书还想看角色怎么说话、怎么行动，则在家庭原有视频时间内选对应配套片段。并非“每天一本＋一集”，也不需要连刷；同一本可以多次阅读或反复看喜欢的一段。

**收到全套以后抽查三组信息即可**：①纸书和新版13主题目录、旧版对应是否一致；②两本已审书新版正文/成人提示是否有变动；③视频能否正常使用、是否对应本册、**对白与策略歌曲分别是什么语言**，以及激活有效期和设备/地区要求。客服说“中文版”暂不等于整集所有歌曲中文翻唱。

## 五、八条容易跑歪的家庭用法

| 常见误解 | 更稳妥的处理 |
|---|---|
| 情绪管理＝不哭不生气 | 情绪可以有，伤人行为需要限制 |
| 自控＝马上服从成人 | 解释安全界限，也尊重孩子表达 |
| 共情＝永远让别人优先 | 自己与他人的需要都重要 |
| 分享＝必须让出玩具 | 可以拒绝，并尝试轮流与协商 |
| 抗挫＝必须坚持到底 | 可以暂停、求助、再试 |
| 责任＝必须立刻道歉 | 先了解事实，支持补救 |
| 社交＝每个人都必须喜欢你 | 同伴能拒绝；欺负要找成人帮忙 |
| 学会SEL＝会背正确答案 | 实际表达、相处、修复比背诵重要 |

**视频+绘本不会自动形成有效教育**，成人日常的倾听、安抚、示范和保护仍是关键。PBS家长资料强调通过简短重复歌曲记住一些调节方法，但也强调先承认儿童感受：[PBS 2026年说明](https://www.pbs.org/parents/thrive/daniel-helping-kids-handle-big-feelings-with-stories-and-music)，[PBS父母指南](https://www.pbs.org/parents/thrive/how-daniel-tigers-neighborhood-can-help-parents-and-grandparents)。
